# Budget script

A live "scripting language" made for budget calculations, higly inspired by Apple math notes.

**Variables**

To create a variable you place a `=` before a uniq name.

example:
`name = 10`

**Data**

Curently only numbers are allowed

**Operators**

`-`
`*`
`-`
`/`
`()`

**Output**

to view outupts in editor use the `#` sign

### Code example

```
income = 10000

netflix = 100
youtube = 100

expenses = netflix + youtube

income - expenses # 9800 kr
```
